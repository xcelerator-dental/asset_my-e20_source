# asset_my-e20_source

Hosted front-end assets for embedding My E20 Dentist sections into Webflow.

- `e20-webflow.css` — combined styles.css + home.css, namespaced under `.e20-embed` (load site-wide via <link>)
- `app.js` — FAQ accordions, finance calculators, scroll-reveal, parallax (load site-wide via <script defer>)

Served over CDN via jsDelivr, e.g.
`https://cdn.jsdelivr.net/gh/xcelerator-dental/asset_my-e20_source@main/e20-webflow.css`
